# SFX placeholders

These 7 files are synthesized placeholder tones (short sine-wave beeps),
generated by a one-off script, not real sound design. Replace them with real
audio whenever it's ready — no code changes needed as long as the filename
(minus extension) stays the same.

`SoundManager` looks for `<name>.ogg` first, then falls back to `<name>.wav`,
so dropping in a `merge.ogg` next to (or instead of) `merge.wav` is enough to
switch it over.

| File          | Fires on                                              |
|---------------|--------------------------------------------------------|
| `merge.wav`   | Two units merged into a higher level                    |
| `spawn.wav`   | A unit spawned from a facility                          |
| `dismiss.wav` | A unit dismissed to the Prince                          |
| `levelup.wav` | The Prince gained a level                                |
| `monster.wav` | A monster spawned on the grid                            |
| `reward.wav`  | A Wall Gate reward was claimed                           |
| `click.wav`   | A main nav button was tapped (Build/Inventory/Explore/Raid/Gold/Prestige) |

A missing file is silent, not a crash — see `SoundManager`'s missing-key cache
(same pattern as `SpriteManager`'s magenta-fallback handling for sprites).
